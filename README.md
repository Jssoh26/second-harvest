# Second Harvest

*Giving food a second life!*

Prototype web app for CC0006 Sustainability (T22 B6): smart food-waste bins, collector routing to black soldier fly (BSF) facilities, BSF intake quotas, a marketplace for frass and BSF feed paid with Harvest points, and buyer feedback analytics.

Open `index.html` or visit the GitHub Pages site. Data is sample data and is saved in each visitor's browser.
